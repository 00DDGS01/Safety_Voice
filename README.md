# 🔊 안전한 목소리 (Safe Voice)

> **말 한마디로 나를 지켜주는 기술**
> 사용자가 지정한 트리거 단어를 음성 인식하여 자동으로 녹음과 비상 연락을 시작하는 안전 어플리케이션

## 💡 프로젝트 배경

일상에서 예측하지 못한 위협 상황이 발생했을 때 결정적인 증거가 되는 것은 **현장 녹음 파일**입니다. 실제 형사 사건에서도 재판 과정에 공개된 녹음 파일이 유죄 판결의 핵심 증거로 작용한 사례가 있습니다.

하지만 기존 녹음 앱은
- 사용자가 **직접 버튼을 눌러야** 녹음이 시작되고
- **계획된 일을 기록**하는 데 초점이 맞춰져 있어

정작 갑작스러운 위협 상황에서는 사용할 수 없다는 한계가 있습니다.

**안전한 목소리**는 성폭력·언어폭력·구두 계약 분쟁 등 갑자기 발생하는 위급 상황에서 **가해자가 모르게, 그러나 법적으로 안전하게** 증거를 남길 수 있도록 설계된 서비스입니다.

## ⚖️ 법적 안전성

> **통신비밀보호법 제14조** — 누구든지 공개되지 아니한 타인 간의 대화를 녹음하거나 전자장치 또는 기계적 수단을 이용하여 청취할 수 없다.

- **본인이 직접 참여한 대화**는 녹음해도 법적 효력이 인정됨
- 제3자 간 대화의 비밀 녹음은 처벌 대상

**법률사무소 공헌**의 검토를 받아 서비스가 위 조항 범위 안에서만 동작하도록 설계했으며, **검토 의견서를 통해 앱 기능의 법적 효력을 인정**받았습니다.
추가로 녹음 파일의 증거 가치를 높이기 위해 **해시값 생성**과 **GPS·기기 정보 등 메타데이터 기록**을 함께 반영했습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🎙 **트리거 단어 인식** | 사용자가 직접 등록한 단어(예: "잠깐만요")를 발화하면 자동으로 녹음 시작 |
| 👤 **화자 인증** | 등록된 사용자 목소리와 대조해 오탐 최소화 (제3자 발화로는 실행되지 않음) |
| 🚨 **비상 연락 자동 발송** | 비상 연락용 트리거 단어 발화 시 GPS 위치와 함께 지정 연락처로 위기 문자 전송 |
| ☁️ **클라우드 자동 백업** | 녹음 종료 후 파일을 즉시 클라우드에 저장해 기기 손상·탈취에 대비 |
| 📁 **사건 폴더 관리** | 사건 단위로 녹음 파일을 묶어 관리, 달력 모드/파일 모드 제공 |
| 🤖 **GPT 기반 사건 요약** | STT 텍스트를 요약해 사건 개요를 자동 생성 및 DB화 |

## 🧭 사용자 시나리오

```
1. 갑작스러운 위협 발생
   사전에 설정한 트리거 단어 발화 → 단어 인지 + 화자 인증 → 가해자 몰래 녹음 시작
                 ↓
2. 위협 지속
   비상연락망용 트리거 단어 발화 → 단어 인지 + 화자 인증 → 비상연락처로 위기 문자 전송
                 ↓
3. 상황을 벗어남
   앱에서 녹음 중지 버튼 클릭 → 녹음 중지 후 클라우드에 안전하게 저장 → 법적 증거 수집 성공
                 ↓
4. 사건 파일 관리
   사건 폴더 생성 → 녹음 파일 이동 + GPT 요약 → 사건별 파일 관리
```

## 📱 UI 흐름 (Flutter, 5단계)

| # | 화면 | 설명 |
|---|---|---|
| 1 | 달력 모드 | 날짜별 사건 발생 현황을 한눈에 확인 |
| 2 | 파일 모드 | 사건 파일 목록 및 용량·개수 확인 |
| 3 | 트리거 설정 | 목소리 학습, 녹음/비상연락 단어 및 비상 연락처 3개 등록 |
| 4 | 녹음 중지 | 녹음 진행 상태 표시 및 중지 확인 |
| 5 | 사건 폴더 관리 | 사건 설명(GPT 요약) + 개별 녹음 파일 관리 |

## 🔍 개발 과정에서 해결한 문제

| 문제 | 해결 |
|---|---|
| 트리거 단어 인식 후 실제 녹음까지 **4~5초 지연** 발생 | **롤링 오디오 버퍼** 방식 도입 — 상시 버퍼에 음성을 유지하다 트리거 인식 시 버퍼 구간부터 저장하여 처리 속도를 2.1초로 단축 |
| 주변 사람의 발화로 인한 **오탐** | 트리거 단어 매칭 + **화자 인증**을 결합해 본인 발화(0.82)와 제3자(0.61)를 분리 |
| 비밀 녹음의 **법적 리스크** | 법률사무소 검토 의견서 확보, 본인 참여 대화로 범위 한정 + 해시·메타데이터 기록 |
| 수동 배포로 인한 반복 작업 | **GitHub Actions → Docker Hub → EC2** 자동 배포 파이프라인 구성 |
